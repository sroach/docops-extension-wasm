# Agents

A Rust based project to create svg visuals from text based markup.

* the svg characterists
* the svg supports light & dark mode and auto detects using the media query css feature
* it uses the premium AI skill when designing the svg visuals
* the library is compiled to WebAssembly
* the github repo has a documentation that is published to github pages maintained locally in the docs/index.html file
* when introducing a new type of visual or update there are html files in the visuals directory that support the Rust type
